# カスタム学習ヒアリング / Custom training intake

- 目的と利用環境 / purpose and target deployment
- クラス定義、難例、除外対象 / class spec, difficult cases and exclusions
- データの取得元、利用範囲、保管期限 / data provenance, permitted use and retention
- シーン・時間・カメラをまたぐ分割方法 / split strategy across scene, time and camera
- 顧客承認済みデータで測る精度・速度・失敗基準 / agreed accuracy, latency and failure criteria
- 成果物、再学習、変更管理と保守の範囲 / outputs, retraining, change control and maintenance

ラベルレビュー、合意した分割での評価、導入環境での確認を見積もりの対象とします。受領前にデータの利用権限と機密情報の取り扱いを確定します。 / Scope the labeling review, evaluation on the agreed splits and integration validation. Confirm permitted data use and confidentiality before collecting files.
